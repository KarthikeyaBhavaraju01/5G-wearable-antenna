# 5G-wearable-antenna
This project focuses on the design and analysis of a compact and flexible 5G wearable antenna for modern wearable communication systems. The antenna is designed using a textile-based substrate and operates around the 3.5 GHz frequency range suitable for 5G n77/n78 bands. The project mainly aims to achieve good return loss, low SAR, compact size, and stable performance for on-body applications.

The antenna was designed and simulated using CST Microwave Studio. Various parameters such as S-parameters, VSWR, radiation characteristics, and SAR analysis were evaluated to ensure efficient wearable performance under bending and body-loading conditions.

The proposed antenna can be used in smart healthcare devices, fitness wearables, wireless body area networks, IoT systems and future wearable technologies. The results demonstrate good bandwidth, flexibility, and reliable communication performance making the design suitable for future 5G wearable applications.
